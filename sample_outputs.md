## Sample 1: SQL vs NoSQL Databases

**Research Query:**  
Difference between SQL and NoSQL databases.

**Tools Used:**  
- Web Search
- Source Reading

**Sources Retrieved:** 3

**Research Findings:**

| Feature | SQL | NoSQL |
|---|---|---|
| Schema | Fixed schema | Flexible schema |
| Data Model | Tables and rows | Documents, key-value, graphs and columns |
| Scalability | Commonly vertical | Commonly horizontal |
| Transactions | Strong ACID support | Depends on database; many support ACID transactions |
| Use Cases | Banking, ERP and relational applications | Real-time applications, IoT and flexible data storage |

**Conclusion:**  
SQL databases are suitable for structured data, relational queries and strong consistency requirements. NoSQL databases are useful when applications need flexible data models and scalable distributed storage.
